# Mesa Pública 🐟

Mesa de mercado compartida entre amigos: el análisis del día (tendencias,
volatilidad, rangos vivos, movimiento en bloque y señales del sistema) más el
registro personal de operaciones y el plan de disciplina de cada quien.

- **Solo por invitación** (lista de invitados + login propio; RLS por usuario).
- **Sin credenciales de bróker y sin ejecución de órdenes**: cada quien opera
  en su propio bróker; aquí se lleva la disciplina.
- Los datos de mercado los publica la mesa privada del administrador
  (solo mercado — nunca operaciones personales de nadie).

**No es recomendación de inversión.** Herramienta educativa privada.
